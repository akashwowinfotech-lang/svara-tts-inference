## Deployed change

For long preset requests, synthesize a bounded opening utterance and retain
its complete generated SNAC codes and exact transcript. Condition every later
phrase on that same opening, while retaining the selected preset label in
both text turns. No waveform encoding round trip or pitch adjustment is used.
The opening is bounded to 24 estimated spoken units / 90 characters where
word boundaries permit, keeping room in the 2048-token context for later text
and generation. Each request owns its reference; concurrent clients never
share one. Short requests and user-supplied reference conditioning retain
their existing path. Endpoint paths and request fields are unchanged.

The model's published preset convention is Language (Gender):
[Svara model card](https://huggingface.co/kenpath/svara-tts-v1).

## Rejected experiments

A cropped audio-only reference and a transcribed reference without the
preset label introduced incorrect opening words in the closing paragraph.
These versions were not deployed. A complete reference with the preset label
in both text turns passed the closing-paragraph transcription check.
